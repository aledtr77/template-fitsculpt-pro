## 🚀 Quick Start Guide

### Prerequisites
Make sure you have Node.js (v18+) installed on your computer.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/16-fitsculpt-coach-lp.git
   cd 16-fitsculpt-coach-lp
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:3000`.

4. **Build production distribution**:
   ```bash
   npm run build
   ```
   The compiled static website will be output to the `dist/` directory ready for deployment on GitHub Pages, Vercel, Netlify, or Cloudflare Pages.
